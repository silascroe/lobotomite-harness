# Mini project smoke test

Build a compact, polished one-page project for a fictional app called “Signal Garden.” This is a faster browser-build exercise than the full Static page smoke test.

Inspect the project first and record a short plan with `workflow_checkpoint`. Create exactly three dependency-free files: `index.html`, `styles.css`, and `app.js`. The page should have a clear heading, a short description, one primary action, and a small interactive status element that changes when the action is used. Use semantic HTML, visible focus styles, responsive layout, and a restrained visual system. Do not use a framework, CDN, remote font, or external image.

Read the files back after creating them. Run `node --check app.js` as the local validation command, then review the complete change with `git_diff`. Finish with an honest summary of what exists and what was checked.
